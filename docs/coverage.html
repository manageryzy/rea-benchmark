Grammar points

C++11: variadic templates, scoped enums, captures, unique_ptr and moves, deleted copy, virtual override/final, constexpr/static_assert, noexcept, exceptions and observable cleanup order.

C++14: generic lambdas, move-only init capture, make_unique, deduced returns, decltype(auto), constexpr loops, binary literals, digit separators and transparent comparison. Its dedicated handler is an ERR:STANDARD control in C++11 and is excluded from C++11 active-point totals.

Languages, optimization and ABI

The multipoint C++/Rust/Go cases cover text counts, ledgers, stable ranking, dependency scheduling, wide argument/aggregate return handling and policy dispatch. Targets are optimized with normal symbols stripped. C++ includes System V / Microsoft x64 boundaries and both libstdc++ string ABIs; Rust includes native/C; Go includes ABIInternal. Native reconstructions are behavior-tested, not certified as binary-compatible replacement libraries.

Coverage means selected behavior, not every API overload or specialization. Repeated handlers across ABIs and Rust tool profiles are correlated.
