# Sanitized public result cache

`summary.json` is generated by the existing report entrypoint from local cached
results. It contains allowlisted scalar measurements and labels, rather than raw
provider JSON or transcripts. The public generator validates its exact schema and
never copies it into the Pages artifact.

Run `make reports` where the matching private dataset exists to refresh it without
model calls. Run `make reports-public` in any source checkout to regenerate the
HTML-only global site. See [publication details](../../docs/publishing.md).
